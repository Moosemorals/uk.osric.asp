# Archive

The frozen record. Nothing here is maintained: an entry keeps the words, the numbers and the links it
had when it was retired, so a citation written against it still means what it meant. A later decision
does not edit these files; it is recorded in [decisions](../decisions.md) instead. See
[decisions](../decisions.md) for the rule that retired the numbered record, and
[archived plans](../plans/archive/README.md) for the plans whose work has landed.
