# Archived plans

Plans whose work is implemented move here and are frozen. They record what was decided and why at
the time, against the code of the time; they are not maintained. A later plan that changes the same
code updates its own document, not these, and a statement here that has since been overtaken is
expected rather than a defect.

`docs/plans/` holds only work that is still proposed or in progress.
