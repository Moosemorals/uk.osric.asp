## Idea

The record is in the repository, and the assistant reads the page store, so it cannot see what is
already queued and proposes work that is already an item. A `/backlog` page — the item list rendered
from those files by the build and seeded like any other, or written by hand and kept honest — would
let the assistant ask "is this already known?" and let the owner share the list with it.
