# Archived items

An item whose work merged moves here and is frozen. It records what was asked and the plan that
answered it, against the code of the time; it is not maintained. A later change that alters the same
code writes its own item and its own `## Plan`, not an edit to these.

The index is [closed.md](../closed.md), which keeps each item's slug — or the legacy `IDEA-` number an
older one was cited by — and links the file. A citation of a closed item still resolves; that is the
whole reason the rows and these files are kept together.

The plans written before 2026-11-24 are still files, and those archive to
[docs/plans/archive](../../plans/archive/README.md); nothing new is written there.
